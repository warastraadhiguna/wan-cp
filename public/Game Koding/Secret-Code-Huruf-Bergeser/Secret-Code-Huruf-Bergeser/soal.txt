# SECRET CODE — MISI 2: HURUF BERGESER
# Cocok untuk anak 10–11 tahun. Terdapat 10 soal cerita berurutan.
# GESER = jumlah langkah huruf yang DIPAKAI SAAT MEMBUAT SANDI (maju).
# Untuk memecahkan sandi, anak harus menggeser huruf MUNDUR sesuai GESER.
# Contoh: JAWABAN: BUKU, GESER: 1, PESAN: CVLV
# Jika PESAN tidak ditulis, aplikasi bisa membuatnya otomatis dari JAWABAN.
# Pisahkan setiap soal dengan baris ===.

===
JUDUL: 01. Surat di Dalam Kotak
TEMA: Jejak Awal
CERITA: Kotak yang ditemukan di taman ternyata berisi surat berisi kode huruf bergeser. Pesan pertama menunjukkan benda yang harus dicari.
GESER: 1
PESAN: QFUB
JAWABAN: PETA
PETUNJUK: Gambar yang menunjukkan arah atau lokasi.
TEMUAN: Di dalam kotak ada PETA sekolah dengan tanda silang dekat sebuah pohon.
PENJELASAN: Setiap huruf sandi digeser mundur 1 langkah. Q→P, F→E, U→T, B→A. Hasilnya PETA.
WAKTU: 80
